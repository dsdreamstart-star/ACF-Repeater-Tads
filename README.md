# ACF-Repeater-Tads
我使用wordpress系統並使用Element編輯器與ACF Pro外掛，我要開發一個elementor widget的外掛，有關可以抓取ACF Repeater的Tads的外掛，該widget的基礎設定欄位有三個，

1. Repeater Field Name

2. tab title (主要是使用Repeater Sub Fields其中一個欄位)

3. tab content，可以選擇elementor template

，該widget也包含三大頁籤(設定、樣式、進階)，在設定的大頁籤內就是我剛剛提到的三個基礎設定，樣式的大頁籤內有兩大項目的樣式設定(標題：字型設定與顏色設定與背景色設定與邊框設定也包含一般與懸停與active與padding、內容：字型設定與顏色設定與padding)，進階的大頁籤就是elementor widget原生的進階設定，外掛名稱和widget名稱都叫做”ACF Repeater Tads”，請協助我開發
